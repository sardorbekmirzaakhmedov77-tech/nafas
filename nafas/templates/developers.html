Public API

Every number on this site is available as JSON. No key needed. Responses allow cross-origin requests, so you can call them from a browser.

GET/api/v1/cities

All cities with their current reading.

GET/api/v1/cities/<slug>

One city and its current reading. Slugs are lowercase city names, such as tashkent or samarkand.

{
  "slug": "tashkent",
  "name": "Tashkent",
  "region": "Tashkent City",
  "latitude": 41.2995,
  "longitude": 69.2401,
  "current": {
    "time": "2026-10-05T14:00",
    "us_aqi": 85,
    "category": "moderate",
    "category_name": "Moderate",
    "pm2_5": 28.6,
    "pm10": 53.9,
    "nitrogen_dioxide": 20.1,
    "ozone": 40.4,
    "sulphur_dioxide": 8.7,
    "carbon_monoxide": 488.0
  }
}

GET/api/v1/cities/<slug>/history?hours=24

Hourly readings for the past hours (1 to 744, default 24).

GET/api/v1/cities/<slug>/forecast

Hourly forecast for the next four days, plus a daily summary with the lowest, highest and average index.

Notes

  • Times are local Uzbekistan time (UTC+5), at the start of each hour.
  • Concentrations are in µg/m³.
  • Unknown cities return 404 with an error message.
